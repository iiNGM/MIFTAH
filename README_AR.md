# 🔑 مفتاح (MIFTAH) — فاحص ومحلل الذاكرة الاحترافي لنظام Windows

برنامج سطح مكتب احترافي مستقل (**`MIFTAH.exe`**) مخصص لأنظمة **Windows 10 / Windows 11 (64-bit)**، صُمم بالكامل باللغة العربية واتجاه **Right-to-Left (RTL)** مع أيقونة مخصصة متعدّدة الدقات (`miftah.ico`) تجمع بين رمز **المفتاح الذهبي السيبراني** و**شريحة الذاكرة الإلكترونية (IC Memory Chip)**، وفق المبادئ المعمارية المتقدمة لهندسة فحص الذاكرة المتوازي وتقسيم الملفات (`Multi-Part Chunking`).

- **المستودع الرسمي للتحديثات:** `https://github.com/iiNGM/MIFTAH`

> **⚠️ تنبيه وإخلاء مسؤولية (Disclaimer):**
> صُمم برنامج **(مفتاح - MIFTAH)** للأغراض التعليمية، أبحاث الهندسة العكسية، فحص وتصحيح البرامج، والألعاب الفردية (Single-Player / Offline) فقط. **يُحظر استخدامه مع ألعاب الأونلاين التنافسية المزودة بأنظمة حماية ضد الغش (Anti-Cheat مثل EasyAntiCheat أو BattlEye أو Vanguard)** لتجنب تعرض حسابك للحظر.

## 1. أبرز المميزات الهندسية والوظيفية

1. **هوية بصرية مخصصة وواجهة عربية أصلية بدون إطار تقليدي (Frameless Dark Mode RTL):**
   - يحمل البرنامج اسم **(مفتاح - MIFTAH)** في شريط العنوان المخصص، نوافذ الحوار، شريط الحالة، ومعرّف شريط مهام نظام Windows (`AppUserModelID: MIFTAH.MemoryScanner.1.0`).
   - أيقونة احترافية مدمجة داخل ملف `.exe` (`RT_GROUP_ICON` بست درجات دقة: `16x16`، `32x32`، `48x48`، `64x64`، `128x128`، و`256x256`) ومعروضة مباشرة في شريط العنوان العلوي وشريط مهام Windows.
   - مصممة منذ البداية باللغة العربية مع ضبط دقيق لاتجاه `Qt.RightToLeft` ومعالجة ثنائية الاتجاه (`Bidi Isolates`) لعرض العناوين السداسية العشرية (`0x00007FF6...`) والأرقام الإنجليزية والوحدات (`MB/s`) من اليسار إلى اليمين (`LTR`) دون أي انعكاس أو تداخل.
   - دعم كامل لمقاييس عرض شاشات Windows عالية الكثافة (`100%`، `125%`، `150%`، `200%`).

2. **محرك فحص ذاكرة حقيقي عبر Windows API (`ctypes`):**
   - استعراض العمليات الجارية مع رقم `PID`، اسم العملية، المعمارية (`64-bit` / `32-bit`)، واستهلاك الذاكرة.
   - الاتصال الآمن بالعمليات عبر `OpenProcess` وفحص الصفحات الملتزمة القابلة للقراءة عبر `VirtualQueryEx` مع تخطي صفحات الحماية `PAGE_GUARD` و`PAGE_NOACCESS`.
   - القراءة والكتابة المباشرة في الذاكرة عبر `ReadProcessMemory` و`WriteProcessMemory`.

3. **الجدولة المتوازية وتقسيم الكتل (`TScanController` & `TScanner` Architecture):**
   - تقسيم نطاقات الذاكرة الكبيرة إلى كتل (`Memory Chunks`) قابلة للتخصيص مع **معالجة حدود الأجزاء المتداخلة (`Boundary Overlap`)** لضمان عدم ضياع أي قيمة تقع بين نهاية كتلة وبداية الكتلة التالية.
   - توزيع المهام على مجمع خيوط العمال (`Worker Thread Pool`).
   - كتابة النتائج الجزئية لكل خيط في ملفات مستقلة (`ADDRESSES-<id>.TMP` و`MEMORY-<id>.TMP`) بدون أقفال تزامن معيقة (`Lock-Free I/O`)، ثم دمجها ذرياً في `ADDRESSES.TMP` و`MEMORY.TMP` مع الاحتفاظ بنسخة التراجع (`ADDRESSES.UNDO` / `MEMORY.UNDO`) ونسخة المسح الأول (`ADDRESSES.First` / `MEMORY.First`).
   - عرض النتائج عبر جدول افتراضي مربوط بالخرائط الذاكرية (`mmap` / `VirtualFoundListModel`) في زمن ثابت $O(1)$ لعرض ملايين النتائج دون استهلاك الذاكرة العشوائية (`RAM`).

4. **أنواع الفحص والبيانات المدعومة:**
   - **أنواع الفحص:**
     - المسح الأول (`First Scan`)، المسح التالي (`Next Scan`)، مسح جديد (`New Scan`)، والتراجع عن المسح (`Undo Scan`).
     - قيمة محددة (`Exact Value`)، قيمة ابتدائية غير معروفة (`Unknown Initial Value`)، أكبر من (`Bigger Than`)، أصغر من (`Smaller Than`)، قيمة زادت (`Increased Value`)، قيمة نقصت (`Decreased Value`)، قيمة تغيرت (`Changed Value`)، وقيمة لم تتغير (`Unchanged Value`).
   - **أنواع البيانات:**
     - `1 Byte`، `2 Bytes`، `4 Bytes`، `8 Bytes`، `Float`، `Double`، والنصوص `String ASCII`، `String UTF-8`، و`String UTF-16`، بالإضافة إلى البحث السداسي العشري (`Hexadecimal`).

5. **التحكم اليدوي اللحظي في سرعة الفحص (`Token Bucket Rate Limiter`):**
   - خوارزمية `Token Bucket` حقيقية مدمجة داخل حلقة القراءة للتحكم في السرعة بوحدة `MB/s` أثناء الفحص.
   - أوضاع جاهزة: **اقتصادي (`Eco — 50 MB/s`)**، **متوازن (`Balanced — 250 MB/s`)**، **أداء فائق (`Performance — 1000 MB/s`)**، **مخصص (`Custom`)**، و**غير محدود (`Unlimited`)**.
   - دعم الإيقاف المؤقت (`Pause`) والاستئناف (`Resume`) والإلغاء الآمن (`Cancel`).

6. **تعديل وتجميد القيم (`Value Editor & Freezer`):**
   - إضافة العناوين من نتائج البحث أو يدوياً إلى القائمة السفلية.
   - تعديل قيمة عنوان منفرد أو مجموعة عناوين دفعة واحدة (`Batch Edit`).
   - تجميد القيم (`Freeze`) وإلغاء التجميد (`Unfreeze`) مع التوقف التلقائي الفوري في حال إغلاق العملية المستهدفة.
   - حفظ واستعادة قوائم العناوين بامتداد `.miftah` (مع التوافق العكسي الكامل مع `.mscope`).

7. **نظام التحديث التلقائي الذكي والآمن (`In-App Auto-Updater` مربوط بـ `iiNGM/MIFTAH`):**
   - فحص آلي في الخلفية عند بدء تشغيل البرنامج عبر `GitHub Releases API` أو ملف `update.json` على المستودع `iiNGM/MIFTAH`.
   - التحقق الأمني من بصمة الملف (`SHA-256 Checksum`) وترويسة الملف التنفيذي (`PE MZ Header`) قبل التثبيت، مع دعم استخراج `MIFTAH.exe` تلقائياً إذا كان ملف الإصدار بصيغة `.zip`.
   - الاستبدال الذاتي لملف `MIFTAH.exe` (مع دعم تصعيد صلاحيات المسؤول `UAC` تلقائياً إن كان البرنامج داخل مجلد محمي مثل `Program Files`).

## 2. طريقة التشغيل الفوري (بدون Python)

1. شغّل الملف التنفيذي المستقل **`MIFTAH.exe`** مباشرة بالنقر المزدوج (أو "تشغيل كمسؤول" لفحص العمليات التي تتطلب صلاحيات مرتفعة).
2. اضغط على زر **"🔍 اختيار عملية..."** في أعلى اليمين، واختر العملية المراد فحصها ثم اضغط **"اتصال بالعملية المحددة"**.
3. اختر **نوع القيمة** و**نوع البحث**، وأدخل القيمة المطلوبة ثم اضغط **"▶ المسح الأول (First Scan)"**.
4. بعد تغير القيمة داخل البرنامج الهدف، أدخل القيمة الجديدة (أو اختر `قيمة زادت` / `قيمة نقصت`) واضغط **"⏭ المسح التالي (Next Scan)"**.
5. انقر مرتين على أي نتيجة في جدول النتائج العلوي لإضافتها إلى **قائمة العناوين المحفوظة** بالأسفل، حيث يمكنك تعديل قيمتها أو تفعيل خانة **"تجميد"**.

## 3. طريقة البناء من الكود المصدري

إذا رغبت في إعادة توليد الأيقونة وبناء الملف التنفيذي `MIFTAH.exe` من الكود المصدري على نظام Windows 64-bit:

```powershell
# تنفيذ سكربت البناء والاختبار الآلي الشامل
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

سيقوم السكربت تلقائياً بالتحقق من الاعتماديات (`requirements.txt`)، توليد الأيقونة (`assets/miftah.ico`)، تشغيل 26 اختباراً آلياً شاملاً، تجميع `MIFTAH.exe` عبر `PyInstaller`، واختبار الملف التنفيذي الناتج.
